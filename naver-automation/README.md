# 네이버 자동입력 로컬 서버 v3

## 핵심 변경

- 웹앱에서 `HTML 생성 + 자동입력으로 보내기` 버튼 하나로 처리
- 웹앱에서 `포스팅 자동입력 실행` 버튼으로 npm start 역할 실행
- 로컬 서버는 `start-server.bat`으로 실행
- 자동화 브라우저 열기 버튼 추가
- 로그인부터 시작하지 않고, 사용자가 자동화 브라우저에서 로그인/글쓰기 화면을 준비한 뒤 포스팅 자동입력만 실행

## 최초 1회 설치

```bash
npm install
npm run install-browser
```

## 매번 사용 순서

### 1. 서버 실행

`start-server.bat` 더블클릭

또는:

```bash
npm run server
```

### 2. 웹앱에서 자동화 브라우저 열기

웹앱 버튼:

```text
자동화 브라우저 열기
```

이 브라우저에서 네이버 로그인 후 블로그 글쓰기 화면을 띄우세요.

### 3. 웹앱에서 데이터 전송

```text
AI 초안 생성
→ HTML 생성 + 자동입력으로 보내기
```

### 4. 자동 입력 실행

웹앱 버튼:

```text
포스팅 자동입력 실행
```

자동화 브라우저의 현재 글쓰기 화면에서:
- 제목 입력
- 대표 이미지 업로드
- 본문 사진 업로드
- 본문 순수 텍스트 입력
- 저장 버튼 클릭

까지 진행합니다.

## 수동 실행용 BAT

- `start-server.bat`: 로컬 서버 실행
- `open-automation-browser.bat`: 자동화 브라우저 열기
- `start-automation.bat`: 자동입력 실행

## 주의

자동화는 일반 크롬이 아니라 Playwright가 여는 자동화 브라우저를 제어합니다.  
따라서 네이버 로그인과 글쓰기 화면 준비도 그 자동화 브라우저 안에서 해야 합니다.

# 화영의블로그자동화

GitHub/Vercel에 바로 업로드 가능한 React + Vite 프로젝트입니다.

## 포함 기능

- 사진/동영상 업로드
- 사진 980px 압축
- IndexedDB 기기 임시저장
- 여러 개 임시저장/불러오기/삭제
- 저장 목록 썸네일 90x60px 표시
- 대표 이미지 직접 선택
- 선택한 대표 이미지를 타이틀 영역에 표시
- AI 생성 결과까지 임시저장/복원
- 생성 중 작업 로그 표시
- 참고 블로그 HTML 자동 정리
- OpenAI API Key 직접 입력 방식

## 배포

1. ZIP 압축 해제
2. GitHub 저장소에 모든 파일 업로드
3. Vercel에서 Redeploy
